# Contributor Covenant Code of Conduct (v2.1, abridged adoption)

We pledge to make participation harassment-free for everyone, regardless of age, body size,
disability, ethnicity, gender, experience, nationality, race, or religion.

**Expected:** empathy, respectful feedback, focus on what is best for the community.
**Unacceptable:** sexualized language, trolling, personal attacks, publishing private info.

Enforcement: report to the maintainers via a private GitHub issue or email listed in `SECURITY.md`.
Violations may lead to warning → temporary ban → permanent ban.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
